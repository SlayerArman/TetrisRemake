# 3AM Tetro 🌙

> A remake of Tetris but specially designed to play at 3AM with dark theme and soothing background music.

This is a Python/Pygame based Tetris game.

## How to Play? 

Downlaod the **3AM Tetro.exe** from the release and also download and extract the assets zip file.

### Itch.io: 

## Controls 🕹️

- **← / A** to Move left
- **→ / D** to Move right
- **↓ / S** to Move down faster
- **↑ / W** to Rotate piece
- **ESC** to Quit game

## Idea

So this project for **3AM** a YSWS of Hackclub. It was mainly about building something with dark theme. At that time I was listening to a very soothing and nostalgic music. so I thought to build a game with that music as in background. And then I got ideaa for building a retro game for more nostalgia and yeah I went with Tetris. The Epic game by Nintendo.

### New Changes

The previous game build was of dark & relaxing theme but now I have added spooky sprites and new music.
