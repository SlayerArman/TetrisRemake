# 3AM Tetro 🌙

> A remake of Tetris but specially designed to play at 3AM with dark theme and soothing background music 
This is a Python/Pygame based Tetris game

## How to Play 

Downlaod the **3AM Tetro.exe** from the repository files.

## Controls 🕹️
| Key | Action |
|---|---|
| `←` / `A` | Move left |
| `→` / `D` | Move right |
| `↓` / `S` | Move down faster |
| `↑` / `W` | Rotate piece |
| `ESC` | Quit game
